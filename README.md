# GitHub homepage source

Personal site for **sssQi198**, meant for the GitHub Pages user site at:

`https://sssQi198.github.io/`

## Preview locally

No build step. Open the HTML file in a browser:

```bash
# macOS
open index.html

# Linux
xdg-open index.html

# or start a tiny static server from this folder
python3 -m http.server 8080
# then visit http://localhost:8080
```

## Publish

1. Create a **public** repository named `sssQi198.github.io`.
2. Put `index.html` (and this folder’s other files) at the **repository root**.
3. In **Settings → Pages**, set source to **Deploy from a branch**, branch `main` (or `master`), folder `/ (root)`.
4. After a few minutes, open `https://sssQi198.github.io/`.

Do not put student IDs, private homework, passwords, or tokens in this repository.
